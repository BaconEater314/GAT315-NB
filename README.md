# Raylib - Physics Edition
This fun little physics engine for messing around with spheres. Will likely keep you entertained for at least 2 minutes.

## Features
- Create a sphere that may or may not have gravity or be affected by anything.
- Connect spheres with springs.
- Create lots of spheres really fast.

## How To Control
- Left-Click to create a sphere.
- Use the UI menu on the left to change the values of the next sphere/spring you create.
- Right-Click to connect the sphere with springs.
- Press Space or the Simulate button to pause and unpause the button.
- Hold Control while Left-Clicking to create a lot of spheres really fast.
